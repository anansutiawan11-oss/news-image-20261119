A program that draws one image summing up the world's news of Thursday 19 November 2026 as a newspaper front page: the Trump–Xi–Putin summit in Shenzhen, the ICJ ruling that Myanmar committed genocide against the Rohingya, Anthropic's record $81.3B IPO, Ukraine's third strike on the Crimea bridge, Israeli tanks pushing into central Gaza, the GTA VI launch, and a record $190.4M Van Gogh sale. Node 22, standard library only — it draws the whole image in code (flat vector shapes plus a bitmap font atlas) and writes a deterministic 1024×1024 PNG. No network at runtime.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
